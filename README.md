# 📚 StudySync

An AI-powered study companion designed to help students stay focused, organized, and productive.

## ✨ Features

- 📅 Smart Study Planner
- ⏱️ Pomodoro Timer
- 🤖 AI Study Assistant
- 📈 Progress Tracking
- 🏆 Leaderboards
- 👥 Study Groups

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- Supabase
- Bolt.new

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Aryanrathor007/StudySync.git
```

### Install dependencies

```bash
npm install
```

### Run the project

```bash
npm run dev
```
